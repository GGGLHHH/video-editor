对照本地剪映调研（`docs/research/jianying/` 01–11 篇和附录、194 张剪映截图）和我们发布版的截图，分五块审查：布局与播放器、时间轴、属性面板与关键帧、文字字幕与素材面板、快捷键导出与设置。每条缺口都在代码里确认过确实没有；标了「待实测」的是剪映那边的行为调研里没写、按剪映习惯推断的。

- **影响**：大 = 剪辑时天天碰到、明显不顺手；中 = 常用功能少了一块；小 = 细节或少数人用。
- **工作量**：小 = 一天内；中 = 两三天；大 = 一周左右。
- 语音识别、AI、要剪映在线素材库 / 云端 / 账号的东西不算缺口，列在最后。

## 三、细节（影响小）

- 时间轴：标记有颜色（Alt+M）、可拖；工具栏「裁剪」按钮和裁剪窗口；点轨道空白处播放头跳过去（待实测）；标尺半秒处写帧号「15f」；轨道头是类型图标（我们写 V1 / S1 / A1）；右键「导出所选片段」「打开文件所在位置」「保存为预设」；「组合」（Ctrl+G，和复合片段不同）。
- 属性面板：组标题行的 `‹ ◇ ›`；旋转拨盘；色温 / 色调渐变滑轨；「应用全部」；视频没声音时不显示「音频」标签。
- 播放器：比例菜单分横竖屏、带图标和平台名，「原始」打勾；参考线（Ctrl+;）和标尺；选中框角点是白圆点（我们是方块）；布局「竖屏创作（左）」「重置当前布局」。
- 文字和素材：字幕列表搜索；特效卡片显示效果示意图；导入 LRC / ASS 字幕；贴一段稿子按句拆成字幕；「贴纸」标签（导入透明图片）。
- 其他：顶栏草稿名可直接改名（待实测）；快捷键方案（FCP X / Premiere）和改键冲突确认；导出静帧；首次进入的新手引导。
