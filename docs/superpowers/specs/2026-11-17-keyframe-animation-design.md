# 关键帧动画 设计

状态：已实现（2026-11-17）。用户确认方向时说的是「推进把」。

## 目的

剪辑中常用的「画面推近」「字幕 / 台标飞入」「强调闪动」都要让画面属性随时间变化。这一轮让视频轨片段的画面属性（位置、缩放、旋转、裁剪、不透明度）可以打关键帧，预览和导出完全一致。

非目标（以后再做）：音量关键帧、曲线编辑器、按单个属性分别打帧的界面、贝塞尔手柄、旋转超过一圈的插值。

## 数据（ve-core）

- 新模块 `keyframe.rs`：
  - `Easing`：`Linear` / `EaseIn` / `EaseOut` / `EaseInOut`，默认 `EaseInOut`。缓动作用在「这个关键帧到下一个关键帧」这一段上。
  - `Key { at: Time, value: f32, easing: Easing }`：`at` 是相对片段起点的时间，吸附到帧。
  - `Prop`：`X`、`Y`、`Scale`、`Rotation`、`Opacity`、`CropLeft`、`CropTop`、`CropRight`、`CropBottom`。以后音量等属性往这里加。
  - `Animation`：按属性分开存，每个属性一串按时间排好、时间不重复的关键帧（`BTreeMap<Prop, Vec<Key>>`）。
- 片段多一个字段 `animation`，为空时不写进文件。工程文件升到第 4 版（1–3 版都能读），理由和第 3 版相同：让旧程序拒读新文件，而不是悄悄丢掉动画。
- 求值：`Clip::transform_at(offset)`。有关键帧的属性按时间插值，没有的用原来的固定值。第一个关键帧之前取第一个的值，最后一个之后取最后一个的值。插值是两端值的凸组合（缓动曲线落在 0–1 之间），所以两端合法、中间也合法（缩放范围、不透明度、裁剪之和）。
- 旋转按存的角度直接插值（-180°～180° 之内）；跨 180° 时会走另一边，属于已知限制。
- 不变式：每个关键帧的值对该属性合法、时间不重复且已排序、都是有限数。

## 编辑（ve-core/edit.rs）

- `add_keyframe(clip, at)`：在 `at` 处把当前所有画面属性（按 `transform_at(at)` 的值）都记成关键帧。
- `apply_transform_at(clip, at, t)`：界面改属性统一走这里。片段没有动画时等同于 `set_transform`；有动画时，有关键帧的属性在 `at` 处新建或更新关键帧，其余属性改固定值。
- `remove_keyframe(clip, at)`：删掉 `at` 处所有属性的关键帧。删完一个关键帧都不剩时，固定值取删除前 `at` 处的值，画面不跳。
- `set_keyframe_easing(clip, at, easing)`。
- 已有操作要照顾动画：
  - 修剪起点：关键帧跟着内容走，时间减去修剪量。
  - 分割：左段保留切点之前的关键帧，并在切点补一个当时的值；右段在 0 处补同样的值，再接上切点之后的关键帧（时间平移）。缓动曲线在切点处只是近似。
  - 复制和移动：关键帧是相对时间，不用改。
- 解析图层：`resolve_layers` 用 `transform_at` 求值；`LayerSource` 多一个 `max_scale`（整个片段里的最大缩放），导出按它决定解码尺寸，避免放大时画面糊。

## 界面（ve-app，照剪映的习惯）

- 属性面板「画面」区标题行加按钮：
  - ◆ `tf-key`：播放头不在关键帧上时「添加关键帧」，在关键帧上时「删除关键帧」。
  - `tf-key-prev` / `tf-key-next`：跳到上一个 / 下一个关键帧。
- 播放头在关键帧上时，显示四个缓动按钮 `tf-ease-linear` / `-in` / `-out` / `-inout`，当前选中的高亮。
- 片段有动画时，面板里的数字显示播放头那一刻的值，播放、拖播放头时跟着更新。在面板里改数字、在预览上拖动、拖不透明度滑块，都走 `apply_transform_at`（自动在播放头处新建或更新关键帧）。「重置」同时清掉动画。
- 时间轴上的片段底部用小菱形标出关键帧位置。
- 一次拖动、一次滑块拖动仍然只算一步撤销。

## 测试

- 核心层：插值与缓动、端点之外取端点值、凸组合保证合法、加 / 删 / 改缓动、修剪起点和分割后画面不变（逐帧比较求值结果）、工程文件 v4 存取，旧版本能读、属性测试（随机关键帧序列求值后结果总是合法）。
- 合成：导出和预览一致性测试里加一层带关键帧的画面，导出某帧和预览同一时刻比较。
- 界面：◆ 打帧、跳转、删帧；有动画时预览拖动在播放头处生成关键帧；面板数字随播放头更新；缓动按钮。
