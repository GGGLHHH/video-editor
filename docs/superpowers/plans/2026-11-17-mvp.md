# 视频剪辑器 MVP 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出设计稿里的 MVP：导入、单视频轨 + 背景音乐轨 + 字幕轨剪辑、撤销重做、流畅预览、导出 H.264 mp4、工程存取。

**Architecture:** Cargo 工作区五个 crate，依赖只向下：`ve-app → ve-engine / ve-export → ve-media → ve-core`。`ve-core` 是无 IO 的纯模型，承担大部分测试；`ve-media` 进程内链 FFmpeg；`ve-engine` 用工作线程 + 无锁环形缓冲做播放；`ve-export` 拼 ffmpeg 滤镜图跑可执行文件；`ve-app` 用 gpui-kit 0.10 画界面。

**Tech Stack:** Rust 1.99（edition 2024）、gpui-kit 0.10.0、ffmpeg-next 9.1（链 scoop `ffmpeg-shared`，FFmpeg 9 / avformat 63）、cpal、rtrb、serde / serde_json、proptest、cargo-llvm-cov、cargo-deny、cargo-machete。

**Spec:** `docs/superpowers/specs/2026-11-17-mvp-design.md`

## Global Constraints

- 不提交、不推送：用户规定只有明确要求时才 commit（各任务的「提交」步骤改为「跑 `scripts/check.ps1` 全绿」）
- `FFMPEG_DIR` 指向 `C:/Users/Administrator/scoop/apps/ffmpeg-shared/current`；运行时 DLL 走 PATH
- `[profile.*.build-override] opt-level = 3`：否则 ffmpeg-sys-next 的 bindgen 构建脚本栈溢出（已实测）
- lint：工作区 `[workspace.lints]` 统一配置，`-D warnings`；生产代码禁 `unwrap/expect/panic/todo/unimplemented/dbg!/print*`，测试里允许
- `unsafe_code = "deny"`；确需时局部 `#[expect(unsafe_code, reason = "...")]` + `// SAFETY:` 注释
- 覆盖率门槛：`ve-core` / `ve-engine` / `ve-export` / `ve-media` 行覆盖 ≥ 90%，全工作区 ≥ 80%
- 性能：1080p60 在完整应用里播放 ≥ 59 fps；拖动预览从松手到画面更新 < 100 ms（1080p H.264，关键帧间隔 2 秒内）
- 时间单位：`Time(i64)` flicks，`FLICKS_PER_SECOND = 705_600_000`
- 界面文字中文；字体走系统栈（中文 `Microsoft YaHei`）

## Review Focus

- 素材文件被删 / 移动后打开工程：应提示缺失并能继续用其余素材，不能崩（Task 3 `load_project_missing_asset_is_reported`，Task 18 UI 提示）
- 可变帧率 / 无音轨 / 纯音频 / 图片当视频导入：探测要给出正确时长和流信息，无音轨的视频片段静音（Task 7 `probe_video_without_audio`，Task 10 `mix_clip_without_audio_is_silent`）
- 在时间轴最末尾、片段边界上、播放头恰好在剪切点时 split / trim：不产生零长度片段（Task 4 `split_at_clip_edge_is_noop`、proptest 不变式）
- 播放中做编辑（删掉正在播的片段、撤销）：引擎换时间轴后从当前播放头继续，不卡死不串音（Task 11 `set_timeline_while_playing`）
- 字幕含中文、换行、`{}` / 逗号 / 反斜杠等 ASS 特殊字符：导出后字形正确不被当成标签（Task 12 `ass_escapes_special_chars`）

### Task 4: ve-core 编辑操作 + 吸附

**Files:** Create `crates/ve-core/src/{edit.rs, snap.rs}`

**Interfaces:**
- Consumes: Task 3 类型
- Produces: `EditError`（`ClipNotFound`、`Overlap`、`OutOfSource`、`WrongTrackKind`、`ZeroLength`）
- Produces（全部 `fn(&mut Project, ...) -> Result<_, EditError>`，失败时工程不变）：
  `append_asset(project, asset: AssetId) -> Result<ClipId>`（视频素材进 V1，纯音频进 A1，放轨道末尾）
  `insert_asset_at(project, asset, track: TrackId, at: Time) -> Result<ClipId>`（与已有片段重叠则报 `Overlap`）
  `move_clip(project, clip, to_track: TrackId, new_start: Time)`（`new_start` 夹到 ≥ 0；重叠报错）
  `trim_start(project, clip, new_start: Time)` / `trim_end(project, clip, new_end: Time)`（夹在素材范围和相邻片段之间；长度 ≥ 1 帧）
  `split_at(project, clip, at: Time) -> Result<ClipId>`（在边界上返回 `ZeroLength`）、`split_all_at(project, at: Time) -> Vec<ClipId>`
  `delete_clips(project, &[ClipId])`、`ripple_delete(project, &[ClipId])`（同轨后续片段左移被删长度）
  `set_gain(project, clip, gain_db: f32)`（夹到 -60..=12）、`set_fades(project, clip, fade_in, fade_out)`（两者和 ≤ 片段长度）
  `add_subtitle(project, at: Time, duration: Time, text) -> Result<ClipId>`、`set_subtitle_text(project, clip, text)`
- Produces: `snap_targets(&Timeline, playhead: Time, exclude: &[ClipId]) -> Vec<Time>`；`snap(t: Time, targets: &[Time], tolerance: Time) -> Option<Time>`

- [ ] 测试：每个操作一条正常路径 + 一条拒绝路径（如 `split_at_clip_edge_is_noop`、`move_into_overlap_rejected_and_project_unchanged`、`trim_end_clamped_to_source`、`ripple_delete_shifts_following`、`fades_clamped_to_length`）；proptest `random_edit_sequences_keep_invariants`（随机 200 步操作后 `check_invariants` 必过）
- [ ] 实现，跑测试
