# 剪辑软件功能全景

参照对象：剪映、Premiere Pro、DaVinci Resolve、Final Cut Pro。

图例：
- **MVP** 列：✅ 第一版要做 · ➖ 第一版不做
- **难度**：指用 Rust + GPUI 自己实现的难度（低 / 中 / 高）

## 1. 素材管理

| 功能 | 说明 | MVP | 难度 |
|---|---|---|---|
| 导入素材 | 视频 / 音频 / 图片，支持拖拽 | ✅ | 低 |
| 素材库 | 缩略图、时长、分辨率、搜索、分组 | ✅（只要列表 + 缩略图） | 低 |
| 代理文件 | 4K / 高码率素材转小文件剪，导出换回原片 | ➖ | 中 |
| 缩略图 / 波形缓存 | 时间轴上的画面条、音频波形 | ✅ | 中 |

## 2. 时间轴编辑（核心）

| 功能 | 说明 | MVP | 难度 |
|---|---|---|---|
| 多轨道 | 视频轨叠加、音频轨混合 | 部分：1 视频轨 + 原声 + 1 条背景音乐轨 | 中 |
| 切割 / 删除 / 移动 / 修剪 | 刀片工具、拖边缘改长度 | ✅ | 中 |
| 吸附对齐 | 贴播放头、贴片段边缘 | ✅ | 低 |
| 波纹删除 | 删一段，后面的自动补上 | ✅ | 中 |
| 滚动 / 滑移 / 滑动修剪 | roll / slip / slide | ➖ | 中 |
| 撤销 / 重做 | 所有操作可撤回 | ✅ | 中（架构一开始就要定） |
| 标记点、入出点 | 粗选再放进时间轴 | ➖ | 低 |
| 嵌套序列 / 复合片段 | 一组片段打包成一个 | ➖ | 高 |

## 3. 预览播放（技术难点）

| 功能 | 说明 | MVP | 难度 |
|---|---|---|---|
| 实时播放 | 音画同步、不掉帧 | ✅ | 高 |
| 拖动预览（scrub） | 拖时间轴画面马上跟 | ✅ | 高（关键帧 seek + 缓存） |

## 11. AI 功能（剪映类卖点）

自动字幕、智能抠像、去背景、口播去气口和废话、自动配乐、数字人、翻译配音。

MVP 都不做。后续最值得做的是**翻译配音**：可以直接对接已有的配音 / 口型流程（见本机 `video-dub-zh2en`、`rt-translate-zh2en` 项目），这块别家很难做得比我们深。
