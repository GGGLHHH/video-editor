# 剪辑软件功能全景

参照对象：剪映、Premiere Pro、DaVinci Resolve、Final Cut Pro。

图例：
- **状态**列：✅ 已做（后面写做到什么程度）· ➖ 还没做
- **难度**：指用 Rust + GPUI 自己实现的难度（低 / 中 / 高）

最近一次对照剪映复审是 2026-11-20（见 `docs/plan.md`「对照剪映复审」「对齐剪映 · 第二轮」「第三轮」「第三轮复审」）。除了语音识别出字幕和 AI 功能，表里的大项都做了；没做的细项、已知限制写在各行里。

## 1. 素材管理

| 功能 | 说明 | 状态 | 难度 |
|---|---|---|---|
| 导入素材 | 视频 / 音频 / 图片，支持拖拽 | ✅ 拖文件进窗口导入；素材卡片拖到时间轴上，拖动中就显示落点（会吸附，拖到轨道之间新建轨道）；文本、调节、特效、滤镜、转场卡片也能拖；卡片上的「+」加到播放头处 | 低 |
| 素材库 | 缩略图、时长、分辨率、搜索、分组 | ✅ 剪映式网格卡片（缩略图、时长、「已添加」）；「音频」标签列出带声音的素材；按文件名搜索、按导入顺序 / 名称 / 时长排序；单击卡片在播放器里预览、右键删除。卡片不显示分辨率，分组还没做 | 低 |
| 代理文件 | 4K / 高码率素材转小文件剪，导出换回原片 | ✅ 播放器 ≡「代理模式」：短边超过 720 的视频在后台生成 540P 副本（按文件路径、大小、修改时间命名，下次直接用），预览用副本，时间轴和导出用原片 | 中 |
| 缩略图 / 波形缓存 | 时间轴上的画面条、音频波形 | ✅ | 中 |

| 鼠标分割模式 / 预览轴 | 剪映的 A / B、S | ✅ B 进分割模式点哪切哪（悬停显示刀线），A 回选择；S 开预览轴，鼠标悬停处直接预览 | 低 |

## 4. 画面处理

| 功能 | 说明 | 状态 | 难度 |
|---|---|---|---|
| 变换 | 位置、缩放、旋转、裁剪、不透明度 | ✅ 预览上可直接拖、拖手柄旋转；属性面板滑块 + 「− / +」微调；工具栏镜像、旋转 90°、裁剪窗口（在原图上拖框、按比例裁）；六个对齐按钮 | 中（GPU 着色器） |
| 关键帧动画 | 属性随时间变化 + 缓动 | ✅ 按属性打帧（位置、缩放（连同缩放 Y）、旋转、裁剪、不透明度、调色、音量、圆角、描边粗细、阴影、色度抠图、蒙版位置 / 大小 / 旋转 / 羽化 / 圆角、特效强度），匀速 / 缓入 / 缓出 / 缓入缓出（对这一刻所有属性的关键帧都有效）；数值框可按住左右拖。HSL 和调整「基础」11 项也能打帧；曲线、色轮不能打帧 | 中 |
| 入场 / 出场动画 | 渐显、放大、滑入…… | ✅ 入场 / 出场 / 组合三组卡片（组合：旋转、摇摆、呼吸），选中后能调时长、能去掉；叠加在关键帧上，不打关键帧 | 中 |
| 变速 | 快慢放、倒放、曲线变速、补帧 | ✅ 常规变速倍数滑条（0.1x–10x）+ 八档快捷，倍数和时长都能直接输入（改时长就是改倍速），声音可保持音调；片段倒放（后台生成倒放文件）；曲线变速 6 个预设 + 自定义（五个点在曲线图上拖，或用滑条，0.1x–10x），预览和导出的声音跟着变；智能补帧「帧融合」（慢放时前后两帧按时间混合；光流法没做） | 中～高 |
| 画中画 / 混合模式 | 叠加、滤色、正片叠底 | ✅ 11 种混合模式（正片叠底、滤色、叠加、变暗、变亮……） | 中 |
| 蒙版 / 抠像 | 绿幕、形状蒙版 | ✅ 6 种形状蒙版（线性、镜面、圆形、矩形、爱心、星形，可羽化、反转），属性面板在「蒙版」时播放器上直接拖（里面移动、方块改宽高、圆点旋转、三角改羽化，一次拖动一步撤销）；一个片段只能有一个蒙版；色度抠图带吸管、强度、阴影；圆角、描边、阴影 | 高 |
| 防抖 | | ✅ 画面 › 视频防抖：裁切最少 / 推荐 / 最稳定（ffmpeg vidstab 两遍，后台生成防抖后的文件，片段换成它；关闭换回原片） | 高（调第三方） |

## 11. AI 功能（剪映类卖点）

自动字幕、智能抠像、去背景、口播去气口和废话、自动配乐、数字人、翻译配音。

都还没做。后续最值得做的是**翻译配音**：可以直接对接已有的配音 / 口型流程（见本机 `video-dub-zh2en`、`rt-translate-zh2en` 项目），这块别家很难做得比我们深。
