# 剪辑软件功能全景

参照对象：剪映、Premiere Pro、DaVinci Resolve、Final Cut Pro。

图例：
- **状态**列：✅ 已做（后面写做到什么程度）· ➖ 还没做
- **难度**：指用 Rust + GPUI 自己实现的难度（低 / 中 / 高）

最近一次对照剪映复审是 2026-11-19（见 `docs/plan.md`「对照剪映复审」）。

## 1. 素材管理

| 功能 | 说明 | 状态 | 难度 |
|---|---|---|---|
| 导入素材 | 视频 / 音频 / 图片，支持拖拽 | ✅ | 低 |
| 素材库 | 缩略图、时长、分辨率、搜索、分组 | ✅ 剪映式网格卡片（缩略图、时长、「已添加」）；「音频」标签列出带声音的素材 | 低 |
| 代理文件 | 4K / 高码率素材转小文件剪，导出换回原片 | ➖ | 中 |
| 缩略图 / 波形缓存 | 时间轴上的画面条、音频波形 | ✅ | 中 |

| 吸附对齐 | 贴播放头、贴片段边缘 | ✅ 时间轴贴播放头 / 片段边缘 / 标记；预览贴画布和其他图层；吸附开关（N），按住 Alt 临时取反 | 低 |

## 3. 预览播放（技术难点）

| 拖动预览（scrub） | 拖时间轴画面马上跟 | ✅ | 高（关键帧 seek + 缓存） |
| 逐帧步进 | 左右键前后一帧 | ✅ | 中 |
| 穿梭播放 | J / K / L 倍速、倒放 | ✅ 倍速声音不变调、倒放有声 | 中 |

| 画面比例 | 16:9 / 9:16 / 1:1 … | ✅ 播放器底栏、草稿参数 | 低 |

## 11. AI 功能（剪映类卖点）

自动字幕、智能抠像、去背景、口播去气口和废话、自动配乐、数字人、翻译配音。

都还没做。后续最值得做的是**翻译配音**：可以直接对接已有的配音 / 口型流程（见本机 `video-dub-zh2en`、`rt-translate-zh2en` 项目），这块别家很难做得比我们深。
