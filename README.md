# video-editor

用 Rust + GPUI（gpui-kit 0.10）写的桌面视频剪辑器。

> 状态：**MVP 完成**，**多轨合成完成**（2026-11-17）。导入、剪辑、多轨叠加（画中画 / 台标）、字幕、背景音乐、预览、导出、工程存取都能用。

## 能做什么

- 界面布局参照剪映专业版：顶栏「菜单」（文件 / 编辑 / 最近打开）和导出按钮，上面素材 / 播放器 / 属性三栏，下面时间轴，各块之间的分隔条可以拖。
- 导入视频 / 音频 / 图片：素材面板的「导入」按钮，或者直接把文件拖进窗口。素材显示成缩略图卡片，带时长；已经用在时间轴上的标「已添加」，悬停点「+」或双击放到时间轴末尾。
- 时间轴：视频轨（带原声）、音频轨（背景音乐）、字幕轨。
  - 视频轨和音频轨可以增删：轨道头左上角「+V」「+A」，每条轨右侧「×」。时间轴上越靠上的视频轨，画面越靠上。
  - 轨道头的开关（照剪映）：🔒 锁定（片段选不中、改不了，批量分割也跳过它）、👁 隐藏（画面 / 字幕不进预览和导出）、🔊 静音（声音不进预览和导出）。空工程时主轨那一行提示「素材拖拽到这里」。
  - 拖动片段可以移动，也可以换到另一条轨；拖片段的边缘可以修剪；位置会吸附到播放头、片段边缘和帧。
  - 支持分割、删除、波纹删除、撤销 / 重做。一次拖拽只算一步撤销。
- 预览：播放、拖动标尺定位、逐帧前进后退，音画同步，字幕直接叠在画面上（白字黑描边）。播放器底栏右边的 ⤢（或 Ctrl+Shift+F）全屏预览，Esc 退出。
- 时间轴工具栏（照剪映）：撤销、恢复、分割、向左 / 右裁剪、删除；定格（在播放头处插入 3 秒那一帧的静止画面，后面的片段往后挪）、镜像、旋转 90°；标记、加字幕；右边主轨磁吸 / 吸附 / 联动三个开关和缩放（全局预览缩放 Shift+Z、缩小、滑块、放大）。
- 属性面板按片段类型分标签（照剪映）：视频片段「画面 / 音频 / 变速 / 动画 / 调整」，字幕「字幕 / 文本 / 动画」，调节片段只有「调整」，没选中时是「草稿参数」（可以直接点选比例、分辨率、帧率）。画面标签的缩放是滑块加数值框，缩放、位置、旋转的数值框两边有「− / +」一格一格调；音频标签调音量（-60 到 +12 dB）、淡入淡出；调整标签有亮度、对比度、饱和度、色温、色调；动画标签套用入场 / 出场预设（视频：渐显、放大、缩小、四个方向滑入滑出；字幕：渐显、向上滑入、放大 / 渐隐、向下滑出、缩小，可一键应用到全部字幕）；字幕标签是全部字幕的列表，点一行跳过去、直接改字、插入、删除。
- 素材面板「音频」：所有带声音的素材，点「+」只把声音放到音频轨末尾（视频文件就是「音频提取」）。「滤镜」：12 个调色预设，点一下套到选中的视频片段（或调节片段）上。「调节 › 自定义调节」：在播放头处加一段 3 秒的调节片段，它下面所有轨道的画面（连同画面外的黑边）一起按它的调色走，预览和导出一致。
- 播放器底栏的「比例」一键切换 16:9 / 9:16 / 1:1 等（保持短边，画面自动适配）。
- 自动保存：改动停下 2 秒后自动存；新工程按日期命名存进草稿目录，顶栏显示上次自动保存的时间。
- 时间轴片段右键菜单：复制 / 剪切 / 粘贴、复制 / 粘贴属性、删除、分割、向左 / 右裁剪、停用片段（停用的片段留在时间轴上，但不播放、不导出）。
- 转场（素材面板「转场」）：叠化、闪黑、滑动、推、推近，挂在选中片段和前一段之间；时间轴切点上有青色小方块。
- 标记：M 在播放头处打标记，Shift+M / Alt+Shift+M 跳到下一个 / 上一个。
- 字幕样式（属性面板「文本」，应用到全部字幕）：预设、字体、字号、粗体、描边、位置。
- 顶栏「布局」：默认布局 / 竖屏创作（播放器在右边占满高度）。
- 变速（属性面板「变速」）：0.25x–5x，素材内容不变、时间轴上的长度跟着变；默认音调不变，打开「声音变调」后音调跟着快慢变；片段上标出倍数。
- 转场处的声音：素材在出点后 / 入点前还有余量时，两段的声音叠在一起交叉淡化；没有余量的一侧在切点处淡出 / 淡入。
- 画面属性（视频轨片段）：位置、缩放、旋转、裁剪、不透明度，在属性面板「画面」区填数字，或者直接在预览上拖（拖框内移动、拖四个角或四条边的中点缩放；拖下方的圆点、或者在四个角外侧一点按住拖动来旋转；「对齐」一排按钮把画面贴到画布的边或中线）。鼠标样式会提示按下去做什么：画面上是手，角上是缩放箭头，旋转区是弯箭头。移动时会吸附到画布和其他图层的边缘、中线，并画出参考线；旋转靠近 0°/90°/180°/270° 会吸过去，按住 Shift 按 15° 一档。在预览上点一下就能选中那一层。
- 关键帧动画（视频轨片段）：「画面」里每一行（缩放、位置、旋转、裁剪、不透明度）右边有一组 `‹ ◇ ›`，只给这一行打帧、跳到这一行的上一个 / 下一个关键帧；组标题的 ◇ 按钮在播放头处记下全部画面属性；之后把播放头移到别处再改属性（填数字或在预览上拖），会自动在那里打关键帧，画面就按时间动起来。◀ ▶ 跳到上一个 / 下一个关键帧，播放头在关键帧上时可以选这一段的快慢（匀速、缓入、缓出、缓入缓出）。时间轴片段底部的小菱形标出关键帧位置。修剪、分割片段后动画保持不变；导出和预览完全一致。
- 带透明的图片（PNG）叠加时保持透明，可以做台标、水印。
- 字幕：在播放头处加字幕，导入 / 导出 SRT。
- 导出 mp4：分辨率（原始 / 720P / 1080P / 2K / 4K，按短边换算）、帧率、码率（更低 / 推荐 / 更高 / 自定义）、视频编码 H.264 / HEVC，「高级」里选显卡（NVENC）或 CPU 编码（NVENC 失败时自动改用 CPU）；对话框底部实时显示时长和估计大小。导出在后台进行，顶栏显示进度，可以取消。
- 工程文件 `.vep`：同时记录素材的绝对路径和相对路径，整个文件夹搬走后仍能找到素材；找不到的素材会列出名字，相关片段显示黑场 / 静音。现在是第 6 版（轨道开关、镜像、调节片段、字幕动画），旧版本的文件都能打开。
- 顶栏 ⌨：全部快捷键一览。

| L / K | 正放（再按 2x→4x→8x）/ 暂停 | Ctrl+Shift+B | 批量分割：切开播放头下所有轨道 |

| ← / → | 逐帧 | [ / ] | 向左 / 向右全选：起点在播放头左边 / 终点在播放头右边的所有片段 |

时间轴从上到下是字幕轨、视频轨（最下面一条是主轨）、音频轨。把片段拖到两条轨道之间（出现白色横线）松手，会在那里新建一条轨道。主轨磁吸开着时，主轨上的片段从 0 开始首尾相接，拖进主轨按位置插队。

选中多个片段时，拖其中任意一个，整组在各自轨道上一起平移。

光标在输入框里时，单键快捷键不生效，打字不会被抢。

## 构建与运行

需要：
- Rust 1.99（仓库里的 `rust-toolchain.toml` 已固定版本）。
- FFmpeg 开发包：本机用的是 scoop 的 `ffmpeg-shared`，`.cargo/config.toml` 里已设置 `FFMPEG_DIR`，换机器时用环境变量覆盖即可。
- `ffmpeg.exe` 和 FFmpeg 的 DLL 要在 PATH 上。
- 构建脚本需要 libclang，并设置好 `LIBCLANG_PATH`。

```sh
cargo run --release -p ve-app                         # 启动
cargo run --release -p ve-app -- 工程.vep              # 打开工程
cargo run --release -p ve-app -- a.mp4 bgm.m4a        # 导入素材并依次放进时间轴
```

## 打包与发布

GitHub Actions 自动做（只打 Windows x64）：
- 推到 main、提 PR：跑全量检查（`.github/workflows/ci.yml`）。
- 推 `v*` 标签：先跑全量检查，再打压缩包，建 GitHub Release（`.github/workflows/release.yml`）。
- 在 Actions 页面手动运行 Release：只生成压缩包，作为运行产物保留 14 天。

压缩包解压即用：`video-editor.exe` + FFmpeg 的 DLL 和 `ffmpeg.exe` + `licenses/`。
附带的是 gyan.dev 的 FFmpeg 9.0.2 完整版（GPLv3），所以压缩包按 GPLv3 分发；源码本身仍是 Apache-2.0。

本机打包：

```powershell
$ff = pwsh scripts/setup-ffmpeg.ps1          # 下载固定版本的 FFmpeg 并校验哈希，放进 target/ffmpeg
$env:RUSTFLAGS = '-C target-feature=+crt-static'
cargo build --release -p ve-app
pwsh scripts/package.ps1 -FfmpegDir $ff      # → dist/video-editor-<版本>-windows-x64.zip
```

## 质量检查

```sh
pwsh scripts/check.ps1            # fmt、clippy（pedantic+nursery+cargo+部分 restriction，-D warnings）、
                                  # 测试、文档、cargo-deny、cargo-machete、覆盖率门槛
pwsh scripts/check.ps1 -NoCoverage
```

覆盖率门槛：
- ve-core / ve-media / ve-engine / ve-export 每个 crate 的行覆盖率不低于 90%。
- 全工作区不低于 80%。

## 性能测量

```sh
# 完整应用里播放 N 秒，帧率写入 ve-bench.log
cargo run --release -p ve-app -- --bench-playback media/test_1080p60.mp4 --seconds 30
# 拖动预览延迟（随机定位 N 次，可选层数）
cargo run --release -p ve-engine --example scrub_latency -- media/test_1080p60.mp4 60 2
# 多层播放：--layers N
cargo run --release -p ve-app -- --bench-playback media/test_1080p60.mp4 --seconds 20 --layers 3
# 导出测速：素材 层数 秒数
cargo run --release -p ve-export --example export_bench -- media/test_1080p60.mp4 3 30
# 端到端演示：拼工程 → 保存 .vep → 导出 mp4
cargo run --release -p ve-export --example demo -- 视频 音频 输出目录
```

2026-11-17 在 RTX 5090 上的实测：

| 项目 | 结果 |
|---|---|
| 1080p60 播放 30 秒 | 59.97 fps |
| 4K60 HEVC 播放 20 秒 | 59.67 fps |
| 拖动预览延迟，关键帧间隔 2 秒 | p99 40 ms |
| 拖动预览延迟，关键帧间隔约 4 秒 | 最长 76 ms |

多轨合成（2026-11-17，游戏同时在运行、显卡占用 84–98%，按最坏情况看）：

| 项目 | 结果 |
|---|---|
| 播放 1 / 3 / 4 层 1080p60 | 58.4 / 57.3 / 52.7 帧/秒（窗口没被遮挡时） |
| 拖动预览 1 / 2 层 | p99 95 / 141 ms |
| 导出 1 层 / 3 层（NVENC） | 277 帧/秒（MVP 275）/ 243 帧/秒（4 倍实时） |

## 代码结构

```
crates/
  ve-core    纯模型：时间（flicks）、工程 / 轨道 / 片段、编辑操作、吸附、撤销重做、调色矩阵、字幕动画、SRT、工程文件
  ve-media   FFmpeg 进程内：探测、视频解码（精确定位 + 缩放 BGRA）、音频解码、缩略图、波形
  ve-engine  播放：时间轴解析、混音、帧缓存、音视频工作线程、声卡输出、以声音为准的时钟
  ve-render  显卡合成（wgpu）：多层画面按位置 / 缩放 / 旋转 / 镜像 / 裁剪 / 不透明度 / 颜色矩阵叠加，输出 BGRA（预览）或 NV12（导出）
  ve-export  导出：合成器逐帧出画面经管道交给 ffmpeg 编码，ASS 字幕和混音走 ffmpeg 滤镜图
  ve-app     GPUI 界面：主窗口、素材库、预览、时间轴、属性、导出对话框
```

依赖只能往下：app → engine / export → render / media → core。
